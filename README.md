# Jaeeon Kim — Research Profile

Bilingual research profile written in Obsidian Markdown and generated with Quartz.

- The root page opens the Korean home; switch to the other language with the `EN`/`KO` control in the left toolbar.
- Edit the pages in `content/en/` and `content/ko/` from Obsidian.
- `custom.scss` contains the purple theme refinements and homepage photo treatment; `static/` contains the language switch and `Beach_Sky.jpg`.
- When rebuilding from a Quartz checkout, copy this folder's `content/` into Quartz's `content/`, `custom.scss` to `quartz/styles/custom.scss`, `static/` into `quartz/static/`, and `quartz.config.yaml` to the Quartz root before building.
- GitHub Pages currently serves the prebuilt site from `main/docs`.
- After editing Markdown or site assets, rebuild with Quartz 5 and replace `docs/` with the generated `public/` output before pushing to `main`.

The public site contains only the generated pages from this project's `content/` directory.
