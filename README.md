# JaeEon Kim — Research Profile

Bilingual research profile written in Obsidian Markdown and generated with Quartz.

- Start at `content/index.md` to choose English or Korean.
- Edit the pages in `content/en/` and `content/ko/` from Obsidian.
- The GitHub Actions workflow builds and deploys the site when changes reach `main`.

The public site contains only the pages in this project's `content/` directory.
